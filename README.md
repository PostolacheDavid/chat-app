# Chat App (React + Redux)

A simple responsive chat application built with React, Redux Toolkit, and custom CSS. This app includes:

- Rule-based chatbot with Redux logic
- Smooth auto-scrolling message view
- Responsive layout with media queries
- Custom modal with Redux control
- Styled scrollbar and animated button feedback

---

## Features

- 💬 Send and receive messages
- 🤖 Bot replies using local rule-based logic
- 📦 Redux state management (messages & modal)
- 📱 Fully responsive layout (mobile to desktop)
- 🎨 Styled chat bubbles, input field, and modal

---

## Tech Stack

- **React** (functional components, hooks)
- **Redux Toolkit** for global state
- **Vite** for fast development
- **Pure CSS** with variables and media queries

---

## Getting Started

### 1. Install dependencies

```bash
npm install

npm run dev

npm run build
```
